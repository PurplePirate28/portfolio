FULL STACK PROJECT

Recipe Finder

A responsive recipe web application built with HTML, CSS and JavaScript using TheMealDB API. Users can instantly search thousands of recipes, explore meal details and discover new dishes through a clean and intuitive interface.

Role
Frontend Developer
Duration
2 Weeks
Technologies
HTML, CSS, JavaScript, REST API
API
TheMealDB

The Problem

Finding cooking inspiration online often requires opening multiple websites before discovering a suitable recipe. Many recipe websites are cluttered with advertisements and unnecessary information, making the experience frustrating.

The objective was to create a simple application where users could search for meals instantly and view detailed cooking instructions without distractions.

The Solution

I developed a responsive web application powered by TheMealDB API. Users simply enter a meal name, and the application retrieves matching recipes in real time.

Each recipe includes an image, ingredients, preparation instructions and category information. The interface was designed to remain clean, responsive and easy to navigate across desktop and mobile devices.

Project Gallery

Screens showing the search experience, recipe cards and detailed meal information.

Key Features

Live Search

Search recipes instantly using TheMealDB API.

Recipe Details

View ingredients, instructions and meal images.

Responsive Layout

Optimized for desktop, tablet and mobile devices.

API Integration

Fetches real-time recipe data from an external REST API.

Outcome

This project strengthened my understanding of working with external APIs, asynchronous JavaScript, responsive layouts and dynamic content rendering.

It also improved my ability to design interfaces that remain simple while presenting large amounts of information in an organized way.
